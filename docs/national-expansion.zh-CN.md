# Pokédex 全国图鉴扩展

已阅读并沿用 `docs/development.md`、`iDex/Recognition/MODEL.md`、
`scripts/replacement/README.md`、数据来源说明、训练计划、独立相机测试协议和

## 工程分析与改动

SwiftUI 负责外屏扫描器和展开后的研究面板，`DexStore` 管理发现记录与浏览状态；
图鉴 JSON、像素图、叫声和 Core ML 分类模型各自独立。原先除了资源只有 151 种，
翻页循环、计数、界面标题、模型标签校验和测试中也写死了 151。

- 图鉴扩为第 1～9 世代共 1025 种，保留原先 151 条图文数据。
- 新增三语名称、分类、说明、属性、身高、体重、六项能力值与叫声。
- 全部使用 96×96 黑白版风格像素图，继续使用最近邻显示；保留原字体、LCD 配色、
  硬件外壳、扫描动画及折叠布局。
- PokéAPI 缺少的 303 条中文说明和 127 条日文说明/分类，使用官方中日文图鉴补齐；
  实际来源、缓存摘要和上游版本分别记录在资源清单中。
- 翻页覆盖全国图鉴并循环回首尾；四位编号和带 `#` 的精确编号搜索得到正确处理。
- 桌面名称、设备标牌、制作信息和错误提示中的品牌改为 **Pokédex**。
  内部工程与安装标识保留，便于沿用构建流程和本机发现记录。

## 模型训练

实际使用本机 RTX 4080 SUPER、CUDA 13.2、PyTorch 2.13.0、TorchVision 0.28.0。
从 ImageNet 初始化 EfficientNet-B0，完成首轮 8 个 epoch，再按计划最多继续 12 个
epoch。独立样本分组在训练前完成；最终测试集只在检查点和接受策略冻结后使用。

当前有 1018 个满足分组训练/验证/测试要求的物种。飘飘雏、海地鼠、波普海豚、
海豚侠、裹蜜虫、蜜集大蛇、铁头壳的独立样本不足或存在相同外形的冲突标注，
保留完整图鉴，但没有空造识别输出类别。实际 ID 与原因以训练覆盖报告为准。

训练结果、标签顺序、来源摘要和低置信度策略随模型保留；照片始终在手机本地识别。
公开图片的分组验证/测试结果不能代替玩偶、卡牌或实物拍摄的准确率。

已知回归：原大葱鸭 #083 像素样例在全国模型中排名靠后且分数接近，未达到确认阈值。
应用会保留候选而不自动确认或计入已发现；测试保留该样例并检查拒绝确认行为。
没有为通过这张样例而放宽阈值，已冻结的测试结果也未用于重新选择模型。

## 验证与安装

跨平台资源检查验证全部 1025 条资料、1025 张有效像素图、1025 个 PCM WAV 叫声、
原 151 条数据一致性与三语字段完整性。iOS 测试另检查真实 Bundle 资源、字体覆盖、
全国翻页边界、搜索、模型输入输出和未确定结果不自动发现。

Windows 负责训练，GitHub 的 Mac 构建负责 Core ML 转换、数值一致性、iOS 测试及打包。
运行 **Build Pokédex National IPA**，成功后下载 `Pokedex-IPA`，按之前跑通的流程签名安装。
当前阶段的实际验证结果请查阅 `TrainingResources` 中的报告，转换前不会把候选模型当作已部署模型。

## 资源来源

- 原 151 张像素图：Pokémon Database Black/White。
- 新增像素图：PokéAPI 默认 Gen 5 风格资源；后续世代由其记录的 Smogon 社区作者制作。
- 名称、说明及数值：PokéAPI CSV；缺失本地化条目来自官方中国与日本图鉴。
- 叫声：原项目固定版本的 PokéAPI/cries；转为同规格 22,050 Hz 单声道 16 位 PCM WAV。
